# Design references

## Arrow Either

`dart_either` uses Arrow's Kotlin `Either` API as one reference when aligning
method names and semantics. Arrow source code is not vendored in this
repository.

- [Arrow Either API documentation](https://apidocs.arrow-kt.io/arrow-core/arrow.core/-either/index.html)
- [Arrow Either source](https://github.com/arrow-kt/arrow/blob/main/arrow-libs/core/arrow-core/src/commonMain/kotlin/arrow/core/Either.kt)
- [Arrow license](https://github.com/arrow-kt/arrow/blob/main/LICENSE)

Any API inspired by Arrow is implemented and documented independently for
Dart's language conventions and type system.
